# framework/assets

Files the framework embeds into what it renders.

- `discovery_report.html` — the template `paramify discovery render` fills for
  every discovery document (see `docs/discovery.md`). One template for every
  platform; the page is self-contained so it opens without network access.
- `open-sauce-sans.woff2` — Open Sauce Sans, the Paramify display face, embedded
  into rendered pages as base64. Licensed under the SIL Open Font License 1.1,
  which permits bundling and embedding. Same file the `docs/diagrams/` pages embed.
